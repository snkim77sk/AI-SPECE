# Cafe24 AI SPACE 배포 가이드 — v2.3 REVIEWED

## 1. 어떤 파일을 올리나요?

`LIGHTING_SKETCH_G2B_DATA_VIEW_v2.3_REVIEWED.zip`을 사용하세요. **기존 v2.2는 배포하지 마세요.**

## 2. AI SPACE 환경변수

최소 아래 항목을 등록합니다.

- `DASHBOARD_USER`: 로그인 아이디
- `DASHBOARD_PASSWORD`: 10자 이상의 강한 비밀번호
- `DASHBOARD_SECRET`: 32자 이상의 임의 문자열
- `G2B_SERVICE_KEY`: 공공데이터포털에서 사용 중인 서비스키
- `G2B_SEED_SAMPLE=0`
- `G2B_API_DAILY_LIMIT=900`
- `G2B_ALLOW_API_URL_EDIT=0`

선택 항목:

- `COMPANY_NAME=주식회사 라이팅스케치`
- `G2B_COMPANY_ALIASES=(주)라이팅스케치,라이팅스케치`
- `G2B_DEFAULT_REGION=인천광역시`
- `G2B_AUTO_SYNC=1`
- `G2B_AUTO_SYNC_HOURS=3`
- `G2B_AUTO_SYNC_DAYS=14`
- `G2B_DB_PATH=/persistent/g2b.sqlite3` — AI SPACE에서 영속 저장 경로가 제공되는 경우 해당 실제 경로로 지정

서비스키와 비밀번호는 채팅에 붙여 넣지 말고 AI SPACE 환경변수에 직접 입력하세요.

## 3. 첫 실데이터 검증 순서

1. 배포 후 로그인
2. 설정 → API 연결 테스트
3. 최근 **1일** 쇼핑몰/물품입찰/용역입찰 수집
4. 화면에서 수요기관, 업체명, 물품식별번호, 단가, 수량, 공급금액 확인
5. 이상 없으면 최근 **14일** 수집
6. 중복건수가 과도하게 늘지 않는지 확인
7. 그 다음에 **최근 3년 구축** 시작

3년 구축은 호출량을 많이 사용하므로 프로그램의 일일 안전한도에 도달하면 중단/대기 상태로 남기고 다음 실행에서 이어서 진행하도록 설계했습니다.

## 4. 데이터베이스 권장

무료체험/기능 검증 단계는 SQLite로 시작할 수 있습니다. 다만 수년치 조달·입찰 데이터를 상시 수집하고 여러 사용자가 동시에 접속하는 정식 운영 단계에서는 PostgreSQL/MySQL로 옮기는 것을 권장합니다.

## 5. 아직 자동화되지 않은 부분

- 기관별 예산 공개자료 자동수집
- 실제 데이터 기반 고급 AI 시장예측 모델
- API 응답의 모든 변경/취소/정정 케이스에 대한 실운영 검증

이 항목들은 첫 실데이터 연결 후 데이터 형태를 확인해서 다음 버전에서 확정합니다.
