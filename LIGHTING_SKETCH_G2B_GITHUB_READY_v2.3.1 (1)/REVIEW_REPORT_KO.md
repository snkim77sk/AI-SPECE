# LIGHTING SKETCH G2B DATA VIEW v2.3 REVIEWED — 재검토 보고서

검토일: 2026-08-15

## 결론

v2.2 AI SPACE판은 **실데이터 배포 전에 수정이 필요한 문제가 확인**되어 그대로 사용하지 않는 것을 권장합니다. v2.3 REVIEWED에서 아래 핵심 문제를 수정했습니다.

## 수정 완료한 핵심 항목

1. **SQLite 실데이터 저장 오류 수정**
   - v2.2의 `ON CONFLICT(source_key)`가 partial unique index와 맞지 않아 실제 API 데이터 upsert 시 SQLite 오류가 발생할 수 있었습니다.
   - v2.3에서 충돌 처리 방식을 수정했고 중복 삽입/갱신 테스트를 통과했습니다.

2. **용역현황 실제 수집 경로 추가**
   - 물품 입찰공고만 수집하던 구조에서 용역 입찰공고 수집을 별도로 추가했습니다.

3. **태양광/분전함/보행신호등 누락 수정**
   - 화면에는 메뉴가 있었지만 수집 필터에서 버려질 수 있던 품목을 수집대상에 추가했습니다.

4. **3년 구축 중 API 호출한도/중단 대응 강화**
   - 일일 안전한도(기본 900회), 호출 카운터, 재시도/백오프, 일일한도/초당제한 오류 구분, 월 단위 재개 커서를 추가했습니다.
   - 페이지 한도 때문에 일부 데이터만 받아 놓고 성공으로 표시되는 문제를 방지하도록 총건수와 페이지 완결성을 확인합니다.

5. **납품요구 수정 건 중복 가능성 완화**
   - 수량/금액 같은 변경 가능한 값 중심의 키 생성을 피하고 납품요구번호·상세순번·물품식별번호 등 안정적인 식별자를 우선하도록 변경했습니다.

6. **인터넷 공개 보안 강화**
   - CSRF 보호, 로그인 실패 제한, POST 본문 크기 제한, CSP 헤더, 공개모드 API URL 수정 잠금, 프록시 클라이언트 IP 전달을 추가했습니다.

7. **우리회사 실적 집계 개선**
   - `주식회사 라이팅스케치`, `(주)라이팅스케치`, `라이팅스케치`처럼 업체명이 다르게 들어오는 경우를 별칭으로 합산할 수 있게 했습니다.

8. **CSV 5,000건 잘림 수정**
   - 화면은 최대 5,000건을 보여 주되 CSV 내보내기는 전체 검색 결과를 대상으로 하도록 변경했습니다.

## 배포 전/후 반드시 확인할 항목

- 실제 공공데이터포털 서비스키로 **1일 테스트 수집**을 먼저 수행합니다.
- 실제 응답 필드명이 정상 매핑되는지 확인합니다. 서비스키 없이 공식 API 실응답까지 검증할 수는 없습니다.
- 1일 수집 정상 → 14일 수집 정상 → 이후 3년 구축 순서로 진행합니다.
- 3년 데이터를 장기 운영할 경우 SQLite보다는 PostgreSQL/MySQL 이전을 권장합니다.
- 예산 메뉴는 현재 자동수집 완성 기능이 아니며 기관별 예산 공개자료 연동이 추가로 필요합니다.
- 시장예측은 현재 통계 기반 추세/평균 분석이며 AI 학습모델은 아닙니다.
