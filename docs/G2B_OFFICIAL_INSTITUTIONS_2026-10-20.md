# G2B 지역별 기관 옵션 공식 자료 대조 (2026-10-20)

## 확인 범위와 사용 원칙

기관이 존재한다는 공식 근거와 해당 기관의 예산 자료가 저장되어 있다는 근거를 구분한다. 공식 목록은 미수집 기관도 선택할 수 있도록 옵션을 보강하는 데 사용하며, 그 자체로 예산 건수·금액·독립 회계기관 코드가 확인된 것으로 취급하지 않는다. 선택한 기관의 저장 자료가 없으면 조회 결과 없음을 표시한다.

기존 정적 목록, 수집된 기관명·코드, 과거 지역·기관명은 보존한다. 현재 명칭으로 과거 원문이나 PostgreSQL 값을 다시 쓰거나, 기관코드를 추정하여 붙이지 않는다. 시도, 시군·자치구, 행정시, 교육청, 교육지원청, 학교는 서로 다른 계층으로 다룬다.

## 행정안전부의 현재 지자체 목록

[행정안전부 지자체 누리집](https://www.mois.go.kr/frt/sub/a04/localGovernment/screen.do)을 2026-10-20에 조회하고, 공식 UTF-8 HTML의 `location_title` 및 `location_list`에서 명칭·상위 지역·실제 링크를 추출했다. 본문에 별도 작성일·기준일은 표시되지 않아 조회일의 현재 목록으로 한정한다.

확인한 목록은 **16개 시도와 하위 229개 링크**이다. 하위 목록에는 **제주시·서귀포시 2개 행정시**가 포함된다. 따라서 229를 독립 지방자치단체 수 또는 예산기관 수로 사용하면 안 된다. 원문 HTML의 SHA-256은 `863a6027d376c936c51fd9585082782b7d8f84371dc4897edfc1b9a6e965a197`이다.

[2026년 지방자치단체 행정구역 및 인구 현황](https://www.mois.go.kr/frt/bbs/type001/commonSelectBoardArticle.do?bbsId=BBSMSTR_000000000055&nttId=128138)은 게시일이 2026-07-24여도 **자료 기준일은 2025-12-31**이다. 이 연간 자료만으로 2026년 7월 이후 현행 체계를 덮어쓰지 않는다.

[제주특별법 제10조제2항](https://www.law.go.kr/LSW/lsLawLinkInfo.do?chrClsCd=010202&lsJoLnkSeq=1000026182)은 행정시를 지방자치단체가 아닌 시로 정한다(시행 2026-10-13). 제주 행정시는 별도 종류로 기록하며 독립 예산기관이라고 단정하지 않는다.

## 교육청과 교육지원청

[교육부 시도교육청 목록](https://www.moe.go.kr/sub/infoRenew.do?m=060104&page=060104)을 2026-10-20 01:01:34 UTC에 조회해 **16개 시도교육청**을 확인했다. 전남광주통합특별시교육청과 강원특별자치도교육청·전북특별자치도교육청의 현행 명칭이 포함된다. 페이지 자체에 발행일·효력일이 없어 이 목록만으로 명칭 전환의 정확한 시행일이나 과거 기관코드의 대응관계를 확정하지 않는다. 기존 광주광역시교육청·전라남도교육청 등 수집 옵션과 과거 코드는 보존한다.

시도교육청은 지방자치단체 본청과 별도 교육행정기관으로 분류한다. 지방교육재정 자료의 시도교육청 단위 `officeName`과 학교·개별 기관 단위 `schoolName`/기관명을 혼합하지 않는다.

교육지원청은 이번 공식 기본 옵션의 일괄 보강 대상에 넣지 않는다.

- [전국교육행정구역표준데이터](https://www.data.go.kr/data/15021156/standard.do)는 기준일 2026-09-20, 수정일 2026-10-06의 공간 경계 자료이며 177개 객체에 세종 본청이 포함된다.
- [교육부 2026-02-12 자료](https://www.moe.go.kr/boardCnts/viewRenew.do?boardID=294&boardSeq=105348&lev=0)는 당시 17개 시도교육청·176개 교육지원청을 설명한다. 현재 시도교육청 목록 16개와 기준시점·자료 성격이 다르다.
- 공간 경계 객체 수를 현재 독립 예산기관 수로 바꾸거나, 세종교육지원청을 추측해서 만들지 않는다. 동부·서부처럼 지역 간 중복되는 기관명도 단독 이름으로 합치지 않는다.
- 교육지원청·학교와 실제 예산 API의 기관 단위·코드 연결이 추가 확인되면 별도 계층으로 보강할 수 있다. 이미 수집된 옵션은 제외하거나 삭제하지 않는다.

## 기관코드와 예산 자료에 대한 남은 확인

[행정표준코드 기관코드 조회](https://www.code.go.kr/stdcode/orgCodeL.do), [법정동코드 조회](https://www.code.go.kr/stdcode/regCodeL.do), [코드 변경 안내](https://www.code.go.kr/bbsmng/dataBbsL.do)의 공개 화면과 개편 공지를 확인했다. 법정동 코드와 7자리 기관코드는 서로 다르며, 이들이 지방재정·지방교육재정 API의 기관코드와 동일하다고 가정하지 않는다. 현존 기관코드 전체 파일과 원천 예산 API 기관코드 사이의 대응관계는 이번 조사에서 확정하지 않았다.

공식 기관 목록만 추가해도 수집하지 않은 예산 자료가 생기는 것은 아니다. 수집된 자료만으로 판단 가능한 기관별 조회 결과 유무를 표시하고, 결과가 없다는 이유로 공식 목록에서 기관을 감추거나 기관 자체가 존재하지 않는 것으로 표시하지 않는다. 자료 미수집과 해당 연도·필터의 예산 0건은 구분 가능한 근거가 있을 때만 별도 설명한다.

## 최소 증거와 재현

전체 웹페이지 원문은 저장소 문서에 복사하지 않고, 아래의 최소 구조화 자료와 추출 스크립트를 함께 보존한다.

- [행안부 시도·하위 목록 JSON](sources/mois_local_governments_2026-10-20.json): 원문 명칭, 상위 지역, 실제 링크, 종류, 조회일과 원문 SHA-256.
- [교육부 시도교육청 JSON](sources/education_offices_moe_20261020.json): 공식 기관명, 지역, 종류, 공식 링크와 조회일.
- [행안부 추출 스크립트](sources/parse_mois_official_directory.py): 공식 HTML을 입력받아 16개 시도·229개 하위 항목을 검증하고 JSON을 생성한다.

PowerShell 재현 예시:

```powershell
$sourceFile = Join-Path $env:TEMP 'mois_local_governments_2026-10-20.html'
Invoke-WebRequest -Uri 'https://www.mois.go.kr/frt/sub/a04/localGovernment/screen.do' -OutFile $sourceFile
python -X utf8 docs/sources/parse_mois_official_directory.py --html $sourceFile --output "$env:TEMP/mois_local_governments_rechecked.json"
```

재조회 시 공식 목록이 달라지면 기존 스냅샷을 덮어쓰지 말고 새 조회일의 자료로 차이를 검토한다. 16/229는 이 스냅샷의 검증값이며 영구적인 개수로 단정하지 않는다.
